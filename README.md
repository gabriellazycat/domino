# TOPPLE

Jogo de dominó tático: monte o caminho de peças e derrube a patrulha antes que ela derrube você.

Versão web (Three.js + Rapier + TypeScript + Vite) — veja [web/](web/README.md).

```bash
cd web
npm install
npm run dev
```

No Windows, dois cliques em `web/Jogar.bat`.

Game design: [docs/](docs/) (GDD v0.2 em `TOPPLE-GDD.pdf`, delta em `GDD-v0.2-DELTA.md`, questões em aberto em `open-questions.md`).
